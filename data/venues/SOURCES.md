# Venue name checks

Every venue is an invented business with an original name. Before a name ships, it is searched
on the web (one quoted query per name) to make sure no real New York City business already
uses it; near-misses go into the `REAL_NYC_BUSINESSES` fixture in
`src/lib/world/places-content.test.ts`, which rejects any venue name that equals or contains
one. Coordinates are plausible, hand-picked points on real streets, checked against the S04
borough, zone and park layers by the same test file.

Searches run 2026-10-06 (web search, US results). Names rejected earlier while planning:
"Low Signal" (Signal, a Brooklyn club), "Velvet Kiln" (Velvet Brooklyn), "Arepa Lucha"
(Arepa Lady).
